# Getting help

- **Something wrong?** Open an issue on the package's own repository, with the
  smallest steps that show it.
- **A question about using a package?** Its README has an "In 30 seconds"
  section and an API table, and its demo page has a Help switch that explains
  every option. If those do not answer it, open an issue and ask.
- **A security problem?** Write to john@johnmorris.ca, not a public issue
  (see SECURITY.md).

Every package is played at [itsutsu.com](https://itsutsu.com), where most of
them began.
